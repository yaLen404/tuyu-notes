# Tuyu Notes（图屿笔记）

> 图屿笔记（Tuyu Notes）是本地优先的双栏笔记：左边画布是知识体系图，右边是被选中笔记的内容。
> 全部存在本机，不联网也能用。

![总览](docs/screenshot-overview.png)

## 它是什么

一张图里放很多卡片，**每张卡片就是一篇笔记**；把卡片拉上连线，就表示两篇笔记互相引用。
点开一张卡片，右边就是它的正文 —— 不用在"编辑器"和"预览"之间来回切。

- 一篇笔记一个 JSON 文件，图片、备份都在本机
- 关窗口前会自动再保存一次；分栏比例、字号、上次看的那篇都会记住
- 界面用 Electron + 原生 JS（没有前端框架）

## 画布

- 拖卡片移动，靠近会吸附并显示参考线；拖四角改尺寸
- 鼠标移到卡片上，四边中点出现圆点，拖到另一张卡片即建立连线
- 点连线可改样式：曲线 / 直线、实心 / 空心 / 无箭头
- 滚轮以光标为中心缩放，拖空白平移
- 左上角可切换多张图；**右键图名**可原地改名或删除这张图

## 笔记

![笔记](docs/screenshot-note.png)

- **富文本块编辑**：单击任意一段就能写，边写边排版；中文与英文 / 数字之间自动留半角空隙
- 块类型：正文 / 标题 1-3 / 无序列表 / 有序列表 / 待办 / 引用 / 代码块 / 公式 / 分割线
- 代码块照 Typora 的手感：自动行号、嵌在代码框内右下角的语言框、语法着色；语言框和最后一行共线，编辑时自动隐藏、鼠标靠近右下角再显示；回车换行、`Tab` 缩进、`↓` 从最后一行离开，末尾空行再按回车也能出来
- 点最后一块下方的空白会直接新开一段并跳过去；最后一块已经空着就聚焦它
- 视图菜单可以只显示左边知识体系图、只显示右边笔记，或恢复左右分栏；中间分界线拖到边缘会实时收起并切单栏，双击恢复 50/50
- 窗口最小宽度 640px，仍能放下左右两栏；贴成半屏时自动只看右边笔记，全屏 / 离开半屏恢复双栏
- 没写语言的代码块停手后会自动识别语言（JS / Python / HTML / JSON / SQL / Go / Rust 等），识别结果写回围栏，也可以随时在右下角手动改
- Shift / Ctrl 点选多块后右键，可以批量改块类型、缩进、勾选，或整体剪切 / 删除
- 直接拖选多行文字后右键，也能把覆盖到的块一起改类型 / 缩进 / 勾选
- 右键图片可以「复制图片」到系统剪贴板，也可以「复制图片引用」`![[文件名]]`
- 空段落里打 `/` 选块类型；也可以直接打 `# `、`- `、`1. `、`[] `、`> ` 自动转换；打 \`\`\`js 回车变代码块
- 回车拆段、`Shift+回车` 段内换行、段首退格合并；列表里 `Tab` 缩进
- 从别处粘贴带代码块 / 表格的 Markdown 时，会保留围栏和表格结构，不再逐行拆成段落
- 直接粘贴带缩进的纯代码时会自动建成代码块，保留行首空格和空行
- 右键菜单和「转为」子菜单会自动避开窗口边缘，底部右键也不会出界
- 窗口 / 任务栏使用和桌面快捷方式一致的图标，不再单独覆盖
- 拖动卡片移动时工具条自动收起，松手后按新位置出现
- 正文写 `[[另一篇标题]]` 建立链接，`#标签` 用来归类
- `Ctrl+V` 直接粘图片，图片存进库里，正文只留 `![[文件名]]`
- 右下角状态栏显示当前字号和这篇笔记的字数

## Windows 安装

从 [Releases](https://github.com/yaLen404/tuyu-notes/releases) 下载
`TuyuNotes-Setup-1.0.2A.exe`，双击安装即可：

- 64 位 Windows 10 / 11；
- 安装时可选择目录，默认创建桌面和开始菜单「图屿笔记」快捷方式；
- 安装包未做代码签名，SmartScreen 可能提示，选择「更多信息 → 仍要运行」；
- 卸载不会删除笔记数据。

## 快速开始

需要 Node.js 18+。

```bash
git clone https://github.com/yaLen404/tuyu-notes.git
cd tuyu-notes
npm install
npm start
```

Windows 上也可以直接双击 `开启笔记.cmd`。

自己打包 Windows 安装包：

```bash
npm install
npm run dist
```

产物在 `dist\TuyuNotes-Setup-1.0.2A.exe`。

## 数据放在哪

`%LOCALAPPDATA%\TuyuNotes\data`

> 更名前的 `%LOCALAPPDATA%\ForYouNotes\data` 会在首次启动时自动复制到新目录，旧目录保留。

| 路径 | 内容 |
| --- | --- |
| `notes\*.json` | 每篇笔记 |
| `app.json` | 图、卡片布局、分栏比例、字号等 |
| `image\` | 正文引用的图片 |
| `backups\` | 自动备份（保留最近 30 份） |

备份和图片都可以从「文件」菜单直接打开所在文件夹。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+N` / `Ctrl+Shift+N` | 新建笔记 / 新建图 |
| `Ctrl+Tab` | 切到下一张图 |
| `Ctrl+S` | 立即保存 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（焦点在正文里时撤的是正文内容） |
| `Ctrl+滚轮` / `Ctrl+0` | 改笔记字号 / 复位 |
| `F5` / `F` | 重排布局 / 适应窗口 |
| `F1` | 使用说明 |
| `Del` | 删除选中的卡片（只在画布有焦点时生效） |

## 开发

```bash
npm install
npm start            # 运行
npm test             # 单元测试（Node 自带 test runner）
npm run uitest       # 界面自检：离屏运行，不会弹窗
npm run capture -- --out=shot.png   # 截图
```

代码结构：

```
main.js            Electron 主进程入口
main/              store（原子写入 + 备份）、窗口、IPC
preload.js         contextBridge 暴露的少量 API
src/               渲染进程：index.html / styles.css / js/*
scripts/           自检与截图脚本（离屏）
test/              单元测试
```
