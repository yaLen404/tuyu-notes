# 笔记栏需求规范

> 范围：右侧笔记栏（标题、正文、块编辑、代码块、图片、公式、表格、链接、撤销与保存）。
> 不包含：左侧知识体系图、连线、窗口边框。
>
> 本文件是**当前有效规范**。最后一节列出已经被后续需求覆盖的旧要求。
>
> 维护来源：`docs/需求总结.md`、`docs/开发约定.md`、`CHANGELOG.md` 及当前实现。
> 最后更新：2026-11-06（对应 1.0.2A 之后的开发版）

---

## 一、定位与布局

1. 笔记栏是右栏，显示**当前选中笔记**的标题和正文。
2. 左侧画布选中哪张卡片，右栏就显示哪篇笔记；画布取消选中时，右栏保留上一篇，不强制清空。
3. 没有笔记可显示时，右栏显示空态提示。
4. 切换到另一篇笔记时，右栏从正文顶部开始显示；同一篇笔记重新显示（例如再点同一张卡片）保持当前上下滚动位置，不能跳到别处。
5. 右栏始终填满剩余宽度，空笔记也不能缩成一条或留出大片黑边。
5. 支持只看右边笔记、左右分栏、半屏自动只看右边；窗口最小宽度 640px。
6. 顶部标题栏包含：
   - 左侧颜色竖条，跟随笔记颜色；
   - 可直接编辑的标题；
   - 标题为空时显示“未命名”；
   - 标题里中英文 / 数字之间自动留空。
7. 底部状态栏只显示当前字号和本篇字数，不再有旧的“连接”区。
8. 正文默认 16px，行高 1.55；中文横向字距额外 0.12em，英文 / 数字 / 链接 / 行内代码保持 0；代码块保持 `letter-spacing: 0` 和 1.4 行高。
9. 菜单栏「设置」点击后弹设置弹窗，不展开下拉菜单；弹窗内可调笔记字号、打开数据 / 备份目录、清理未引用图片、立即备份。

---

## 二、编辑模型

1. **编辑和预览合一**：没有“编辑 / 预览”切换，点正文就能编辑。
2. 整篇正文是**单个 `contenteditable` 宿主**，不再是每个块一个独立编辑根。
3. 块只是视图模型，最终统一存回 Markdown 字符串 `note.content`。
4. 支持原生跨块文字选区：拖选、复制、剪切、跨块删除都按真实文本处理。
5. 单击卡片只选中，不把键盘焦点交给笔记；双击卡片才打开并聚焦笔记。
6. 点击正文后焦点进入笔记；点击画布空白、标题栏或其它区域，笔记块收掉编辑底色。
7. 输入、粘贴、删除、切块后立即写回内存并自动保存；关闭窗口前还会再存一次。

---

## 三、块类型

支持以下块：

- 正文段落
- 标题 1 / 2 / 3
- 无序列表
- 有序列表
- 待办清单
- 引用
- 代码块
- 公式块
- 表格
- 分割线
- 图片（行内）

块的 Markdown 标记、列表编号、任务勾选框、引用线、代码围栏、公式围栏、表格源码都必须能正确往返保存。

---

## 四、块级交互

1. `Enter`：在光标处拆块，光标后的内容进入新块。
2. `Shift+Enter`：同一块内软换行。
3. 块首 `Backspace`：与上一块合并；空块可直接删除。
4. 空块必须保留，不能因为重排被吞掉。
5. 连续回车可以堆出多个空块，重新解析后仍然保留。
6. `Tab` / `Shift+Tab`：列表类块缩进 / 反缩进。
7. 在空段落输入 `# `、`- `、`1. `、`[] `、`> ` 会自动转成对应块。
8. 在段落里输入 \`\`\` 或 \`\`\`js 再回车，会转成代码块。
9. 右键块可以改块类型、缩进、勾选、剪切、复制、粘贴、全选、删除。
10. 点击最后一块下方的空白：自动补一个空段落并聚焦；最后一块已经为空则直接聚焦。
11. 点击块左侧 / 右侧留白：按点击的纵向位置落到对应行，不能跳到文末。
12. 笔记开头有内容标题时，前面的空块收掉，标题贴顶；正在编辑的前置空块不能隐藏。
13. 标题最前面按回车：在标题上方插入空段落，原标题格式和文字保留。
14. 标题上边距：h1 / h2 / h3 为 18 / 14 / 10px；第一个有内容标题贴顶。

---

## 五、文字选区、块多选与菜单

1. 鼠标拖选可以跨块，选区保持原生浏览器选区，不再用紫色块覆盖假装选中。
2. 松手后的 click 不能清掉刚拖出的选区。
3. `Shift` / `Ctrl` 点击块可以块级多选，右键批量操作。
4. 鼠标拖选多行文字后右键，可把覆盖到的块一起转类型、缩进、勾选。
5. 右键菜单包括：
   - 剪切、复制、粘贴、全选；
   - 转为（正文 / 标题 / 列表 / 待办 / 引用 / 代码 / 公式 / 分割线）；
   - 代码块额外有“复制代码”；
   - 图片额外有“复制图片”“复制图片引用”；
   - 删除这一块 / 删除选中。
6. 菜单和“转为”子菜单必须夹在窗口视口内：
   - 下方放不下向上翻；
   - 右侧放不下向左翻；
   - 高度超出时菜单内部滚动。
7. 右键不能改变已有的块选中状态。

---

## 六、删除规范

1. 跨块长选区删除必须把选中的全部内容删干净，不能残留最后一块。
2. 全选整篇删除后，只保留一个普通空块，不能留下空的 `## ` / `- ` / `> ` 标记。
3. 删除后的光标要落在合并位置，不能因为 Markdown 源码长度和渲染长度不一致而偏移。
4. 带粗体 / 链接 / 行内代码的内容被跨块删除时，前后缀要按 DOM 实际内容合并，不能切坏格式。
5. 空代码块里按 `Backspace` / `Delete`：删除整个代码块，焦点落到上一块末尾或下一块开头；整篇只有这一块时留下一个空段落。
6. 空代码块高度只占一行。
7. 代码块行号区域不可编辑、不可点中；点行号只能聚焦代码输入框。
8. 删除内容时，右栏的上下阅读位置要保持稳定：光标可以不跟着视口跳，但视口不能被重排或光标带回删除点。

---

## 七、代码块规范

1. 按 Typora 手感：始终原地编辑，不点开覆盖式 textarea。
2. 左侧自动行号；行号不可编辑。
3. 右下角语言框：
   - 显示当前语言；
   - 编辑代码时隐藏，鼠标靠近右下角或退出编辑后显示；
   - 可搜索、可选择语言、可清空；
   - 支持 `js`、`py`、`csharp` 等别名。
4. 本地语法着色。
5. 没有语言时，停手约 650ms 自动识别语言并写回围栏；手动选过 / 清空过的不再自动覆盖。
6. `Enter` 换行并按 2 个空格自动缩进；`{`、`[`、`(`、`:` 后多缩一级。
7. `Tab` 插入制表符；`Shift+Tab` 反缩进。
8. `↑` 从第一行离开，`↓` 从最后一行离开；末尾空行再回车也能离开。
9. `Ctrl+Enter` 在代码块下方另起普通段落。
10. 代码围栏会自动加长，避免代码里的 \`\`\` 行截断。
11. 代码块首尾空行、空代码块都要能原样保存。
12. 非空代码块块首 `Backspace` 不拆围栏；空代码块则删除整块。
13. 代码里的 `Ctrl+Z` / `Ctrl+Y` 走笔记内容撤销，不触发浏览器全局撤销。
14. 输入法组合期间高亮层继续显示，输入框保持透明；不能整块代码变白，原有语法颜色不能丢。
15. 代码块中文宽度按两个 ASCII 字符格对齐。
16. 代码块内部空白、缩进、复制粘贴必须原样保留。

---

## 八、图片规范

1. `Ctrl+V` 或拖入图片文件，图片存入笔记库 `image` 目录，正文只写 `![[文件名]]`，界面不显示磁盘路径。
2. 图片可正常显示、删除。
3. 纯图片块按 `Backspace` / `Delete` 删除整张图；图文混排删除光标紧邻的图片。
4. 点图片后光标落到图片后面，可直接退格。
5. 右键图片可以复制真实图片到系统剪贴板，或复制 `![[文件名]]` 引用。
6. 普通块复制时，带图片 / 粗体 / 链接的内容不能只复制成纯文字。

---

## 九、Markdown、链接、标签、公式、表格

1. 支持标题、粗体、斜体、删除线、行内代码、代码块、引用、有序 / 无序列表、任务清单、表格、分割线。
2. 支持 `[[另一篇标题]]` 双链：
   - 存在的链接可点击跳转；
   - 不存在的链接显示为“待创建”，点击可创建；
   - 改标题时，其它笔记里指向旧标题的双链自动更新。
3. 支持 `#标签`，点击标签按标签筛选图谱。
4. 支持 `$行内公式$` 和 `$$公式块$$`；有 KaTeX 就渲染，没有也不能吞内容。
5. 表格支持 Markdown 表格、对齐标记；表格源码可编辑。
6. 图片嵌入不算笔记链接；画布连接和正文链接取并集。

---

## 十、粘贴规范

1. 粘贴带代码围栏 / 表格 / 标题 / 列表的 Markdown 时，整段走 Markdown 解析，不能逐行拆成普通段落。
2. 代码围栏内部换行、空行、表格表头与分隔行必须保留。
3. 粘贴带缩进的纯代码（没有围栏）时，自动建代码块，保留行首空格、Tab、空行，并自动识别语言。
4. 普通无格式多行文本仍按原来的逐行拆块行为。
5. 粘贴 Markdown / 纯代码作为单独撤销步骤，可一次撤销。

---

## 十一、撤销、保存与状态

1. 笔记内容撤销 / 重做使用整篇 Markdown 快照。
2. 连续打字合并窗口 300ms；结构化操作单独记一步。
3. 标题改名不重置正文撤销历史。
4. 笔记字号：`Ctrl+滚轮`、`Ctrl+＋/－`、`Ctrl+0`，范围 70%–240%，只影响右栏，不影响画布。
5. 状态栏只显示“字号 + 字数”。
6. 自动保存，`Ctrl+S` 立即保存；关闭窗口前再 flush 一次。
7. 数据存 `%LOCALAPPDATA%\TuyuNotes\data`，一篇笔记一个 JSON，图片在本机，备份保留最近 30 份。
8. 写盘使用临时文件 + rename，避免半截文件。

---
